## Task 2: `LandingView.vue` 구현

**Files:** `src/features/home/LandingView.vue` (전면 재작성)

구조 — 루트 `<main>`이 스크롤러(`h-[calc(100dvh-var(--header-h))] overflow-y-auto`,
`lg:snap-y lg:snap-mandatory`), 섹션 5개는 `min-h-full lg:snap-start lg:snap-always`.

연출 구동(전부 컴포넌트 로컬):
- `heroPlay` — 마운트 후 더블 rAF로 재생(타이틀 마스크 슬라이드업 + 서브·CTA 지연 페이드)
- `vReveal` 로컬 디렉티브 — 마운트 시 숨김 클래스+IO 등록, 교차 시 리빌. RM이면 no-op(기본
  보임). 타임아웃 보험. `delay`·`preClass` 옵션(스테이지 목업 스케일 인 변형).
- `vickStage` 0~4 — IO(threshold .55) 진입 시 [250,1050,1850,2600]ms 타임아웃 시퀀스,
  이탈 시 클리어+0, RM이면 즉시 4. `:class="{ s1:…, s4:… }"`.
- 패럴랙스 — hero mousemove → rAF 스로틀 → frag별 `data-depth` 비례 translate.
  RM 또는 `(pointer: fine)` 아니면 미등록.
- 카운트업 — odds 카드 IO 교차 시 `useCountUp(() => seen ? 1500 : 0, { durationMs: 1100 })`.
- Vibe 루프·lfloat·chev·lxblink — scoped CSS 키프레임. `motion-reduce`에서 정지.

색 — 토큰 클래스 + 다크 위 흰색/스크림 관용구(spec 참조). scoped CSS에서는
`var(--color-*)`와 `color-mix(... var(--color-terra) 92%, transparent)`만.
