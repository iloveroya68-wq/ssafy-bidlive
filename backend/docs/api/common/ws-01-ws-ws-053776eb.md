## 비고

CONNECT 헤더의 Bearer 토큰 검증 후 세션 Principal 확정

> **WebSocket 연결 명세** — STOMP `CONNECT /ws`에서 JWT를 검증하고 세션 Principal을 확정한다.
## 목적
모든 SEND·SUBSCRIBE가 클라이언트가 보낸 회원 ID가 아니라 서버 세션의 `Principal(memberId)`을 신뢰하게 한다.
## 입력
```plain text
CONNECT /ws
accept-version:1.1,1.2
Authorization:Bearer {accessToken}
heart-beat:10000,10000
```
## 처리 규칙
- 토큰 서명·만료·회원 상태를 검증하고 실패하면 `ERROR` 프레임 후 연결 종료
- 성공 시 세션에 `Principal(memberId)`, `tokenExpiresAt`, `connectedAt` 저장
- SEND·SUBSCRIBE의 회원 ID는 세션 Principal에서만 획득
- 토큰 만료 후 SEND는 `AUTH_EXPIRED`로 차단하고 WS-01 재인증을 요구
- 기존 구독 수신은 설정된 grace 기간만 유지하며 `ws.max-session-duration` 초과 시 연결 종료
- STOMP heartbeat 누락 세션은 브로커 정책에 따라 정리
## 성공 결과
```plain text
CONNECTED
version:1.2
heart-beat:10000,10000
```
