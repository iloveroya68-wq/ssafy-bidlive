## 각 화면 개요 (와이어프레임 기준 — 실제 섹션은 빌드 시 해당 `data-screen`과 1:1 대조)

- **landing**: `scroll-snap` 세로 스냅. ① 히어로(부유 파편·타이틀·CTA `3초 만에 시작하기`/`라이브 구경하기`) ② 비크리 봉투 개봉(3봉투 + 낙찰 스탬프, 2등가 강조) ③ 라이브 스테이지 목업(Vibe 칩 루프) ④ 예측 배당 카드(×5/×3/×1.5 바) ⑤ 테라 드렌치 피날레(카카오 CTA). **비크리 비공개(규칙 6)·예측 신설(규칙 7)** 문구 그대로.
- **main**: 예측 수익률 티커 → "지금 열려 있는 라이브" 히어로 캐러셀 + 개설 CTA → 마감 임박 컬럼(카드 리스트). "전체 보기 →" = `/rooms`.
- **signup**: 서비스 소구점 3종 + 카카오 시작 버튼. login과 상호 링크. **이미 `SignupStep.vue`로 구현돼 `/login?mode=signup`에서 동작 중** — 슬라이스 3은 이걸 라우트로 옮기는 작업이다.
- **console**: `data-state`(`wait`/`live` 2종, done 없음). 지표, 연장(N/3)·시작·종료·방 수정/삭제, 질문 큐 패널, 송출 프리뷰(FE2 슬롯). 상태는 서버 판정이라 URL 지정 불가(정적 틀은 목 상태로 표시).
- **charge**: 금액 프리셋·직접 입력, 결제 수단(PG 샌드박스). 전체 화면, 진입 직전 경로로 복귀. **이미 `ChargeModal.vue`로 동작 중** — 모달→라우트 이전.
- **withdraw**: 출금 가능액(홀드 제외)·계좌 등록/변경. **이미 `WithdrawModal.vue` + `stores/wallet.ts`의 `withdrawTradePoint`로 동작 중** — 모달→라우트 이전. `-220`의 "현행 API로 구현 불가" 서술은 실상과 다르므로 슬라이스 6 착수 전 재확인이 필요하다.
