> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 운영자가 신고 접수된 경매를 보고 그 자리에서 강제 종료하는 `/admin` 화면을 붙인다.

**Architecture:** 계약 레이어(`shared/api/admin.ts`)는 실 호출만 한다 — 서버가 이미 붙어 있어 목 분기를 만들지 않는다. 2단계 확인 규칙은 `useAdminForceEnd` composable이 소유하고, 화면은 그걸 쓰기만 한다. 기존 `useDealAction`·`useRoomDelete`와 같은 규칙·같은 상수다.

**Tech Stack:** Vue 3 (`<script setup lang="ts">`) · TypeScript · Pinia · Tailwind v4 · Vitest

## Global Constraints

- 설계 정본: `frontend/docs/superpowers/specs/2026-07-31-운영자-콘솔-design.md`
- **색·폰트 하드코딩 금지.** `bg-terra`·`bg-faint`·`bg-surface`·`text-ink` 같은 토큰 클래스만 쓴다. 새 색을 만들지 않는다 (AGENTS.md 규칙 1)

- 컴포넌트는 렌더 스냅샷을 늘리지 않는다. 깨지면 조용한 것(분기·접근성 속성)만 잡는다

## 서버가 이미 주는 것

슬라이스 1(MR !256, 머지됨)에서 붙었다. 계약 정본은 `backend/docs/api/report/admin-01-get-admin-reports.md`.

```
GET  /api/v1/admin/reports?includeEnded=false&cursor=&size=20   (ADMIN 전용)
POST /api/v1/admin/auctions/{auctionId}/force-end               (ADMIN 전용)
```

- 목록 응답: `{ items: [{ auctionId, title, thumbnailUrl, sellerNickname, status, reportCount, reasonCounts: [{ reasonCode, count }], latestReportedAt }], nextCursor, hasNext }`
- `thumbnailUrl`은 **null일 수 있다**(이미지 없는 상품)
- 강제 종료 요청 `{ reason, adminNote }` → 응답 `{ auctionId, status, resultType, endedAt }`
- 오류 코드: 목록 `INVALID_CURSOR`·`INVALID_SIZE`·`INVALID_INCLUDE_ENDED`(400) / 종료 `AUCTION_NOT_ENDABLE`(409)·`AUCTION_NOT_FOUND`(404)
- **`ADMIN` 계정이 아직 0개다.** 실서버에서 눌러볼 수 없다 — MR에 「못 본 화면」으로 명시한다

```ts
// 운영자 콘솔 API (S15P11A704-525)
//
// 명세 근거
// - 신고 목록:   GET  /api/v1/admin/reports                        (ADMIN-01, 로컬 신설 계약)
// - 강제 종료:   POST /api/v1/admin/auctions/{auctionId}/force-end (DEAL-09)
//
// **목 분기가 없다.** 둘 다 서버에 붙어 있다 — 목이 남아 있으면 연동이 깨져도 화면이 멀쩡해서
// 어긋난 걸 아무도 못 잡는다(`shared/api/mock.ts` 머리말).
//
// 둘 다 `ADMIN`만 열린다. 아닌 회원은 403, 비로그인은 401이며 화면이 그걸 구분해 그린다.

import { http } from '@/shared/api/http'
import type { Id, IsoDateTime } from '@/shared/api/types'

/** 신고 사유 코드. 접수 API(`shared/api/reports.ts`)의 `ReportReasonCode`와 같은 값 집합이다 */
export interface ReportReasonCount {
  reasonCode: string
  count: number
}

export interface ReportedAuctionItem {
  auctionId: Id
  title: string
  /** 이미지가 없는 상품은 null이다 */
  thumbnailUrl: string | null
  /** 서버가 마스킹한 판매자 닉네임 */
  sellerNickname: string
  /** `WAITING` | `LIVE` | `ENDED` */
  status: string
  reportCount: number
  /** 건수 내림차순, 동수면 코드 사전순 — 서버가 고정해 보낸다 */
  reasonCounts: ReportReasonCount[]
  latestReportedAt: IsoDateTime
}

export interface AdminReportPage {
  items: ReportedAuctionItem[]
  nextCursor: string | null
  hasNext: boolean
}

export interface AdminReportQuery {
  /** 기본 false — 종료된 방은 빼고 준다 */
  includeEnded?: boolean
  cursor?: string
  /** 기본 20, 최대 100 */
  size?: number
}

/**
 * ADMIN-01 신고 접수 경매 목록.
 *
 * **집계는 전부 서버 값이다.** `reportCount`와 `reasonCounts` 합이 같은 경매 집합을 세므로
 * 프론트에서 다시 세지 않는다.
 */
export async function getAdminReports(query: AdminReportQuery = {}): Promise<AdminReportPage> {
  // 준 값만 싣는다. `undefined`를 그대로 넘기면 axios가 파라미터를 빼주긴 하지만,
  // 서버 기본값을 쓰는 것과 빈 문자열을 보내는 것이 눈으로 구분되지 않는다.
  const params: Record<string, string | number | boolean> = {}
  if (query.includeEnded !== undefined) params.includeEnded = query.includeEnded
  if (query.cursor !== undefined) params.cursor = query.cursor
  if (query.size !== undefined) params.size = query.size

  // 경로는 baseURL(`/api/v1`) 기준 상대경로다 — `/v1`을 또 붙이면 `/api/v1/v1/...`가 된다(394).
  const { data } = await http.get<AdminReportPage>('/admin/reports', { params })
  return data
}

export interface ForceEndRequest {
  /** 비어 있으면 서버가 400으로 거절한다 */
  reason: string
  /** 명세에 있지만 서버가 저장하지 않는다 — 감사 기록으로 믿으면 안 된다 */
  adminNote?: string
}

export interface ForceEndResponse {
  auctionId: Id
  /** 항상 `ENDED` */
  status: string
  /** 항상 `FORCED` */
  resultType: string
  endedAt: IsoDateTime
}

/**
 * DEAL-09 운영 강제 종료. **되돌릴 수 없다** — 입찰 보류금과 예측 포인트가 환급되고
 * 방이 `ENDED`가 된다.
 *
 * 이미 종료된 방은 409 `AUCTION_NOT_ENDABLE`이다. 다른 운영자가 먼저 눌렀거나 정상 종료된
 * 경우라 화면은 그 행을 목록에서 지운다.
 */
export async function forceEndAuction(
  auctionId: Id,
  request: ForceEndRequest,
): Promise<ForceEndResponse> {
  const { data } = await http.post<ForceEndResponse>(
    `/admin/auctions/${auctionId}/force-end`,
    request,
  )
  return data
}
```

```ts
// 「한 번 더 눌러」를 거치고, 타임아웃과 다른 행 무장으로 자동 해제된다.

/** 무장이 열려 있는 시간. `useDealAction`·`useRoomDelete`와 같은 값으로 맞춘다 */
const CONFIRM_TIMEOUT_MS = 5_000

/** 이 상태면 그 방은 이미 끝났다 — 목록에 남겨두면 눌러도 계속 같은 오류다 */
const GONE_STATUSES = [404, 409]

/**
 * @param remove 종료됐거나 이미 끝난 것으로 확인된 경매를 목록에서 빼는 콜백.
 *   전체 재조회를 하지 않는 이유: 운영자가 보던 자리가 밀려 다음 행을 잘못 누른다.
 */
export function useAdminForceEnd(remove: (auctionId: Id) => void) {
  /** 「한 번 더 눌러」 단계에 들어간 경매. null이면 무장 없음 */
  const armedId = ref<Id | null>(null)
  /** 요청이 나가 있는 경매 */
  const pendingId = ref<Id | null>(null)
  const error = ref<string | null>(null)
  /** 실패한 경매 — 목록에서 **그 줄 밑에** 오류를 붙이려면 어느 건인지 알아야 한다 */
  const errorId = ref<Id | null>(null)

  /** 무장한 행의 사유. 확정 시 그대로 서버로 간다 */
  let armedReason = ''
  let timer: ReturnType<typeof setTimeout> | null = null
  // 응답을 기다리는 동안 화면을 떠나면 뒤늦은 remove가 다음 화면을 건드린다
  let cancelled = false

  function clearTimer() {
    if (timer !== null) {
      clearTimeout(timer)
      timer = null
    }
  }

  function disarm() {
    clearTimer()
    armedId.value = null
    armedReason = ''
  }

  /**
   * 1단계. **다른 행이 무장돼 있으면 먼저 푼다** — 둘이 동시에 무장돼 있으면 각각 한 번씩
   * 눌러 둘 다 끝나고, 운영자는 2단계를 거쳤다고 느끼지 못한다.
   */
  function arm(auctionId: Id, reason: string) {
    disarm()
    error.value = null
    errorId.value = null
    armedId.value = auctionId
    armedReason = reason
    timer = setTimeout(() => {
      if (armedId.value === auctionId) disarm()
    }, CONFIRM_TIMEOUT_MS)
  }

  /** 2단계. 무장되지 않은 행은 아무것도 하지 않는다 */
  async function confirm(auctionId: Id) {
    if (armedId.value !== auctionId) return

    const reason = armedReason
    disarm()
    pendingId.value = auctionId
    error.value = null
    errorId.value = null
    try {
      await forceEndAuction(auctionId, { reason })
      if (cancelled) return
      remove(auctionId)
    } catch (caught) {
      if (cancelled) return
      const status = extractApiErrorStatus(caught)
      if (status !== null && GONE_STATUSES.includes(status)) {
        error.value = '이미 종료된 경매예요.'
        remove(auctionId)
        return
      }
      error.value = '종료하지 못했어요. 잠시 후 다시 시도해 주세요.'
      errorId.value = auctionId
    } finally {
      if (!cancelled) pendingId.value = null
    }
  }

  onUnmounted(() => {
    cancelled = true
    clearTimer()
  })

  return { armedId, pendingId, error, errorId, arm, disarm, confirm }
}
```
