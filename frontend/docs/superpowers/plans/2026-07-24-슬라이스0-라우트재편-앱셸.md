# 슬라이스 0 — 라우트 재편 + 앱셸(AppHeader) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** docs/02 확정 라우트 표대로 라우트를 재편하고, 와이어프레임의 전역 헤더를 `AppHeader`로 신설해 이후 화면 슬라이스(1~6)가 올라탈 네비게이션 골격을 완성한다.

**Architecture:** `/`는 경로를 나누지 않고 `HomeGate.vue` 한 컴포넌트가 `auth.isLoggedIn`으로 `LandingView`/`MainView`를 갈아 끼운다. 목록은 `/rooms`로 이동하되 **라우트 이름 `room-list`는 유지**해 기존 `router.push({ name: 'room-list' })` 호출부를 건드리지 않는다. 신규 화면 6개는 이 슬라이스에서 **최소 stub**으로만 만들어 라우트를 연결하고(빌드 상시 초록), 내용은 슬라이스 1~6에서 채운다. `AppHeader`는 `App.vue`에 상주하며 `route.meta.chrome === false`인 화면에서만 숨는다.

**Tech Stack:** Vue 3.5 (`<script setup lang="ts">`) · vue-router 4 · Pinia · Tailwind v4 (CSS-first `@theme`)

## Global Constraints

- 색·폰트 하드코딩 금지. `src/app/styles/main.css`의 `@theme` 토큰 클래스만 사용 — `bg-cream` `bg-surface` `text-ink` `text-dim` `text-faint` `border-line` `bg-stage` `text-on-dark` `text-on-dark-dim` `text-terra` `bg-terra` `bg-terra-tint` `text-slate` `bg-slate-tint` (AGENTS.md 규칙 1).
- **`tailwind.config.js`를 만들지 않는다** (v4 CSS-first, 규칙 2).
- `package-lock.json` 삭제·재생성 금지, TypeScript `~6.0.x` 업그레이드 금지 (규칙 3).
- FE2 소유 영역 수정 금지: `features/live/media/`·`features/live/socket/`, `features/chat/`, `stores/live.ts` (규칙 4).
- 숫자(금액·시간)는 Tailwind 내장 **`tabular-nums`** 유틸로 자릿수 고정. (`.tnum` 커스텀 유틸은 이 레포에 없다.)
- 컨테이너 컨벤션: `mx-auto max-w-7xl px-6`.
- 커밋: Conventional Commits 한국어, 제목 **끝**에 `(S15P11A704-<번호>)`. **`<번호>`는 착수 직전 생성하는 이 슬라이스의 Jira 이슈 키로 치환한다** — 계획서에 박아둘 수 없어 남긴 유일한 자리표시다.
- **이 레포에는 단위 테스트 프레임워크가 없다**(vitest·@vue/test-utils 미설치). 테스트 프레임워크를 임의로 도입하지 않는다. 각 태스크의 검증은 **`npm run lint` + `npm run build`(vue-tsc 타입체크) + `npm run dev` 수동 라우트 확인 + 와이어프레임 대조**로 한다 (AGENTS.md 커밋 전 조건과 동일).

```ts
    to.path !== '/onboarding' &&
    to.path !== '/login' &&
    to.path !== '/signup'
  ) {
    return { path: '/onboarding', query: { redirect: to.fullPath } }
  }
```
