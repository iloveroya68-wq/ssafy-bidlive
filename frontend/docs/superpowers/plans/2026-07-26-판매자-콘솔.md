# 판매자 콘솔 (슬라이스 4) 구현 계획

> 설계: `docs/superpowers/specs/2026-07-26-판매자-콘솔-design.md` · Jira `S15P11A704-70` · 브랜치 `feat/S15P11A704-70`

**목표:** `/rooms/:id/console`의 stub을 와이어프레임 `data-screen="console"` 기준 화면으로 채운다(대기·라이브 겸용).

**접근:** `ConsoleView.vue`가 데이터(방 상세 + `live` 스토어)를 모아 props로 내리고, 자식 셋(`ConsoleMetrics`·`QuestionQueue`·`BroadcastSlot`)은 스토어를 모르는 표현 컴포넌트로 둔다. 남은 시간은 `useCountdown(endsAt, { serverOffset })`만 쓴다.

**스택:** Vue 3 `<script setup lang="ts">` · Pinia · Tailwind v4 토큰 클래스 · `shared/api/*` 목 어댑터

## 전역 제약 (모든 태스크에 적용)

- 색·폰트 하드코딩 금지. `src/app/styles/main.css` `@theme` 토큰 클래스만 (`bg-cream`·`text-ink`·`text-dim`·`text-faint`·`border-line`·`bg-surface`·`text-terra`·`text-red`·`text-slate`·`bg-stage`·`text-on-dark`·`text-on-dark-dim`).
- 남은 시간을 `Date.now()` 단독으로 계산하지 않는다. `useCountdown(endsAt, { serverOffset: live.serverOffset })`만 쓴다 (규칙 5).
- 진행 중 화면에 타인 입찰 금액·최고가·순위를 표시하지 않는다. 공개 가능 값은 입찰 **건수**·참여자 **수**뿐 (규칙 6).
- FE2 소유 파일 무변경: `src/features/live/media/`, `src/features/live/socket/`, `src/features/chat/`, `src/stores/live.ts`. **import는 자유, 수정만 금지.**
- HTTP는 `shared/api/*` 모듈 경유만. 컴포넌트에서 `fetch`·`axios` 직접 호출 금지 (규칙 8).
- 없는 데이터를 목 숫자로 채우지 않는다. 값이 없으면 `—` 또는 `--:--`.
- 각 태스크 끝: `npm run format` → `npm run lint` → `npm run build` 전부 통과한 뒤 커밋. 커밋 제목 끝에 `(S15P11A704-70)`.
- 커밋 메시지가 여러 줄이면 파일로 넘긴다(`git commit -F <path>`). bash에서 PowerShell here-string 금지.

## 파일 구성

| 파일 | 책임 |
| --- | --- |
| `src/features/console/ConsoleView.vue` (수정) | 프레임. 방 상세 조회, `live` 연결/해제, 상태 판정, 액션 호출, 2열 레이아웃, 목 모드 시연 토글 |
| `src/features/console/ConsoleMetrics.vue` (신규) | 지표 3박스. 대기 세트/라이브 세트를 props로 받아 그리기만 |
| `src/features/console/QuestionQueue.vue` (신규) | 미답변 질문 목록 + 답변 완료 emit |
| `src/features/console/BroadcastSlot.vue` (신규) | 송출 미리보기 자리, 카메라·마이크 컨트롤, 대기 점검 리스트, 종료/삭제 버튼 |

자식 셋은 `useLiveStore`·`useAuthStore`를 import하지 않는다. 그래야 나중에 FE2가 `BroadcastSlot` 내부를 실제 송출로 갈아끼울 때 스토어 결합이 걸리지 않는다.

import { isMockApi } from '@/shared/api/mock'

// BID-05 서버 권위 타이머 — endsAt·serverOffset이 단일 소스다. Date.now() 단독 계산 금지(규칙 5).

  return Number.isNaN(ms) ? null : ms
})
const { display: startsInDisplay } = useCountdown(scheduledAtMs, {
  serverOffset: computed(() => live.serverOffset),
})

## Task 3: 액션 — 시작·연장·수정/삭제 안내 + 403 사후 가드

**Files**
- Modify: `src/features/console/ConsoleView.vue`

**Interfaces**
- Consumes: `startAuctionRoom(auctionId): Promise<StartAuctionRoomResponse>` (`@/shared/api/rooms`), `extendAuction(auctionId): Promise<ExtendAuctionResponse>` (`@/shared/api/bids`), `API_ERROR_CODE`·`hasErrorCode`·`toApiError` (`@/shared/api/errors`)

- [ ] **Step 1: 액션 상태와 핸들러 추가**

```ts
import { extendAuction } from '@/shared/api/bids'
import { startAuctionRoom } from '@/shared/api/rooms'
import { API_ERROR_CODE, hasErrorCode, toApiError } from '@/shared/api/errors'

const actionPending = ref(false)
const actionError = ref<string | null>(null)
/**
 * 판매자가 아님이 **사후에** 밝혀진 상태.
 * 방 상세 응답에 판매자 식별자가 없어(seller는 마스킹 닉네임·평점뿐) 사전 판정을 할 수 없다.
 * 판매자 전용 액션의 403 NOT_AUCTION_SELLER로만 알 수 있다 — 상세 응답에 sellerId 추가는 BE 확인 대상.
 */
const notSeller = ref(false)

const MAX_EXTENSIONS = 3
const canExtend = computed(
  () =>
    !actionPending.value &&
    (live.remainingExtensions ?? 0) > 0 &&
    remainingMs.value !== null &&
    remainingMs.value >= 60_000,
)

function applyActionError(error: unknown) {
  const apiError = toApiError(error)
  if (hasErrorCode(apiError, API_ERROR_CODE.NOT_AUCTION_SELLER)) {
    notSeller.value = true
    return
  }
  actionError.value = apiError.message
}

async function startNow() {
  if (actionPending.value) return
  actionPending.value = true
  actionError.value = null
  try {
    await startAuctionRoom(auctionId.value)
    if (isMockApi()) demoState.value = 'live'
  } catch (error) {
    applyActionError(error)
  } finally {
    actionPending.value = false
  }
}

async function extendFiveMinutes() {
  if (!canExtend.value) return
  actionPending.value = true
  actionError.value = null
  try {
    await extendAuction(auctionId.value)
  } catch (error) {
    applyActionError(error)
  } finally {
    actionPending.value = false
  }
}
```
