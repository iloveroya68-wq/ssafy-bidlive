# 슬라이스 2 구현 계획 — main 화면 (S15P11A704-309)

설계: `docs/superpowers/specs/2026-07-25-main-화면-design.md`

## 순서

각 단계 끝에 `build`가 초록이어야 다음으로 간다. 화면이 중간에도 뜨는 순서로 잡았다.

### 1. 목 데이터

`src/mocks/homeFeed.ts` 신설.

- `LEADERS` — 정본 값 10명 (`name`·`rate`·`bets`·`hits`)
- `HERO_SLIDES` — 정본 `HEROES` 4개(`roomId`·`tag`·`title`·`sellerName`)를 `mockRooms`와 엮는다
- 마감 임박은 별도 목 없이 `mockRooms`에서 파생 (`state === 'live'` → `endsAt` 오름차순 4개)

정본의 `ROOMS[h.ix]` 인덱스 참조는 방 id로 바꾼다 — 목 배열 순서가 바뀌어도 안 깨진다.

### 2. `EndingSoonCard.vue`

가장 작고 의존이 없다. `.endcard` 1장 — 56px 썸네일 + 제목 2줄 클램프 + 메타 + 우측 타이머.

- `useCountdown(() => props.room.endsAt, { urgentMs: 180_000 })`
- 정본은 3분 이하 강조가 목록 카드에 있다(`RoomCard`와 동일 기준)
- 썸네일은 `picsum` + 토큰 배경 폴백

### 3. `HomeTicker.vue`

- 트랙을 2벌 복제해 `translateX(-50%)` 무한 루프 (정본 `.tk-half` 2개 구조 그대로)
- `:hover` 정지, `prefers-reduced-motion`이면 애니메이션 자체를 끈다
- 클릭 → `/me` (리더보드 탭은 Phase 5, 지금은 마이페이지까지만)
- 순위 메달 `🥇🥈🥉` 그 외 `N위`

### 4. `LiveHeroCarousel.vue`

가장 무겁다. 마지막에서 두 번째로 둔다.

- 슬라이드 렌더 + `translateX(-i*100%)` 전환
- dots 클릭 이동, 좌우 화살표(hover 시 노출)
- 자동 전환 3초 — **`mouseenter`·`focusin`에 정지**, 벗어나면 재개, reduced-motion이면 시작 안 함
- 슬라이드별 남은 시간은 `useCountdown` (방마다 `endsAt`이 다르므로 슬라이드당 1개)
- 입찰 틱 3.2초 — 현재 슬라이드만 +1, reduced-motion이면 색 플래시 생략
- `onBeforeUnmount`에서 인터벌 전부 해제

### 5. `MainView.vue` 조립

- 티커 → 헤더 행(소구 문구 + `.serif` 제목 + 방 개설 CTA) → `heroRow`
- `heroRow`: `lg:grid-cols-[1fr_332px]`, 그 아래 1열
- `.hero-all`은 `lg` 이상에서만 absolute, 아래에서는 흐름 배치
- 방 개설 CTA → `router-link` `room-create`, 전체 보기 → `room-list`

### 6. 검증

- `format:check` · `lint` · `build`
- 브라우저(로그인 상태 `/`): 티커 흐름·hover 정지 / 캐러셀 자동·화살표·dots·hover 정지 / 마감 임박 4장 카운트다운 감소
- **회귀**: 비로그인 `/` → landing 정상 (HomeGate 분기)
- 창 폭 축소 → 1열 전환, `.hero-all` 위치 정상
- reduced-motion 강제 후 루프 정지·수동 조작 동작

## 주의

- **`stores/live.ts`·`features/live/socket/`·`features/chat/`를 건드리지 않는다** (규칙 4, FE2 소유)
- 색·폰트는 토큰 클래스만. 새 색이 필요하면 먼저 `main.css` `@theme`에 있는지 확인
- 타이머는 전부 `useCountdown` 경유 — `setInterval`로 초를 깎지 않는다 (규칙 5)
- 비크리 비공개(규칙 6): 히어로·마감 임박 메타에 **최고가·타인 입찰가 없음**. 입찰 건수·참여 인원·하한가만
