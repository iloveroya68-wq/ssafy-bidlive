# 랜딩 봉투 개봉 스크롤 온보딩 (2026-08-06)

MEM-01 랜딩(`LandingView.vue`)에 "봉인된 입찰 봉투가 스크롤로 열리는" 핀 고정 연출을 추가한다.
디자이너가 만든 데모 HTML(봉투 개봉 스크롤 온보딩 컨셉)을 원본으로 하되, 아래 항목은 의도적으로 다르게 간다.

## 데모에서 가져오는 것

- 히어로와 비크리 카드 섹션 **사이**에 핀 고정 봉투 스테이지 삽입:
  스크롤 진행에 비례해 실링왁스 축소 → 플랩 개봉(3D 회전 90° + 안감 전개) →
  편지 인출 → 편지 확대 → 표지("봉인된 입찰 봉투") → 본문("진행 중엔 입찰 건수만 보입니다") 전환.
- 봉투 지오메트리(SVG 날개·플랩·안감 패턴), 종이 질감(feTurbulence), 수신인·우표·소인 디테일.
- 카피 개편: 스테이지가 "마감까지 아무도 모르고, 마감 후 봉투가 열립니다"를 가져가고,
  비크리 카드 섹션 제목은 "최고가가 이기고, 2등가만 냅니다"로. 히어로 스크롤 힌트는
  "한 통의 봉투가 도착했습니다 — 스크롤로 열어보기".

## 데모와 다르게 가는 것 (합의 사항)

1. **휠 하이재킹 없음.** 데모의 `wheel preventDefault` + 스텝 스냅(ScrollToPlugin)은 채택하지 않는다.
   자유 스크롤 + ScrollTrigger scrub만. 이에 따라 기존 `lg:snap-y snap-mandatory`도 제거한다
   (핀 스페이서와 CSS 스냅이 충돌한다).
2. **색은 전부 기존 토큰으로 매핑.** 데모는 웜 테라코타 팔레트인데 규칙 1은 "따뜻한 색조를 섞지 않는다"다.
   봉투 종이는 중성 톤(`surface`·`cream`·`line` 기반 color-mix), 실링왁스·안감·우표는 기능색
   레드(`terra` 계열)로. **새 토큰 추가 없음.**
3. **폰트는 Pretendard 유지** (데모의 Noto Sans KR 링크 미채택).
4. 데모의 나머지 섹션(비크리 카드·라이브 목업·배당·피날레)은 기존 구현과 사실상 동일하므로
   기존 IO 기반 연출을 유지한다 — GSAP은 봉투 스테이지에만 쓴다.

## 기술 결정

- **GSAP(+ScrollTrigger) 의존성 추가.** 핀 고정 + scrub은 IO/CSS 스냅으로 불가,
  CSS scroll-driven animations는 Firefox/Safari 미지원. GSAP은 전면 무료(상용 포함).
- 랜딩 스크롤러는 window가 아니라 `<main class="landing">`(overflow-y-auto)이다 —
  ScrollTrigger `scroller` 지정 필수, 편지 확대 배율도 스크롤러 크기 기준.
- `prefers-reduced-motion`: GSAP 타임라인을 만들지 않고 개봉 완료 정적 상태로 렌더.
- 콘텐츠 인질 금지 원칙 유지: 편지 본문 텍스트는 마크업에 실재하고 연출은 얹기만 한다.
