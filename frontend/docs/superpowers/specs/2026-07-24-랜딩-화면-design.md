# 랜딩 화면 (슬라이스 1) — 설계 (2026-07-24)

## 목표

비로그인 `/`(HomeGate → LandingView)에 뜨는 서비스 소개 랜딩을 와이어프레임
`data-screen="landing"` 기준으로 구현한다. 랜딩은 첫인상이라 **연출이 화면의 본체**다 —
정본의 모든 연출을 재현하고, 팔레트·컨셉("밝은 장터, 어두운 무대") 안에서 마감 품질을 올린다.

## 구성 — 스크롤 스냅 5섹션 (정본 1:1)

| 섹션 | 내용 | 연출 |
|---|---|---|
| `lx-hero` | 다크 스테이지(`bg-stage`), 킥커+점멸 닷, 타이틀 2줄, 서브, CTA 2개, 스크롤 유도 | 타이틀 마스크 슬라이드업(마운트 후 재생), 부유 카드 4장 `lfloat` + 마우스 패럴랙스(depth별) |
| `lx-vick` | "마감까지 아무도 모르고…" + 봉투 3장 + 낙찰 스탬프 | 진입 시 4단 시퀀스(250/1050/1850/2600ms), 이탈 시 되감기·재진입 재생 |
| `lx-live` | "보면서, 물어보면서 지릅니다" + 16:9 스테이지 목업 | 목업 스케일 인, Vibe 칩 무한 루프(`lxvibe`) |
| `lx-pred` | "구경만 해도…" + 배당 카드(×5/×3/×1.5) + 신뢰 밴드 | 바 차오름, 실수령 BP 0→1,500 카운트업(1.1s) |
| `lx-final` | 테라 드렌치 — 워터마크 "2등가", 카카오 CTA, 로그인 링크 | 순차 리빌 |

카피는 정본 그대로. 이미지는 정본과 같은 picsum 목 — 단 배경 마지막 레이어에 `--color-stage`
폴백을 깔아, 못 불러와도 깨진 박스가 아니라 다크 스테이지로 읽히게 한다. 목 이미지를 로컬 에셋으로
바꿀지는 정본이 picsum을 10군데 쓰는 만큼 랜딩 단독이 아닌 **프로젝트 차원 결정**이다(별도 이슈).

## 정본 위에 올리는 마감 (전부 랜딩 범위 안)

1. **리빌이 콘텐츠 가시성을 인질로 잡지 않는다.** 정본은 `.lin{opacity:0}`이 기본이라 IO가
   안 돌면 빈 화면이 출고된다. 기본값은 보이는 상태로 두고, 마운트 후 JS가 숨김→관찰→리빌을
   얹는다(IO는 observe 직후 초기 교차 상태를 반드시 보고하므로 화면 안 요소는 즉시 리빌).
   보험으로 타임아웃 강제 리빌을 둔다.
   단 **봉투 시퀀스(`lx-vick`)에는 보험 타임아웃을 두지 않는다** — 히어로(1.5s)·`v-reveal`(3s)과 달리
   미재생 상태가 "봉인된 입찰 봉투"로 읽혀서 콘텐츠 손실이 아니다. 강제 재생하면 스크롤이
   닿기도 전에 봉투가 열려 내러티브가 깨진다. 의도된 예외다.
2. **`#818181` → `text-dim`.** 정본의 보조 라벨 색은 토큰에 없고 흰 배경 대비 3.5:1(AA 미달).
3. **반응형.** 정본은 데스크톱 전용. `lg:` 미만에서 2열 그리드는 1열 스택, 부유 카드는 숨김,
   타이틀 clamp 하한 완화. **스크롤 스냅은 `lg:` 이상에서만** — mandatory 스냅은 섹션이
   뷰포트보다 길어지는 모바일에서 콘텐츠를 가둔다.
4. **reduced-motion 항목별 처리.** 패럴랙스·무한 루프는 정지, 시퀀스·카운트업은 즉시 최종
   상태. 정본의 일괄 `0.001s`는 무한 루프를 고속 회전시키는 부작용이 있다.
5. **`text-wrap: balance`** — 헤드라인 줄바꿈 균형.

## 재사용·이동

- `useCountUp` — 결과 화면에서 이미 2곳이 쓰는 유틸. 세 번째 사용처가 생기므로 컨벤션대로
  `shared/lib/`로 이동하고 기존 import를 갱신한다(동작 무변경).
- `KakaoAuthButton` — 피날레 CTA에 재사용(`@click` → `/login?mode=signup`).

## 색 처리 원칙

- 팔레트 색은 전부 토큰 클래스. 다크 스테이지 위 흰색·스크림(`text-white`, `bg-white/10`,
  `bg-black/50` 오버레이)은 RevealOverlay·WaitingStage의 기존 관용구를 따른다.
- 정본의 `#FFF0F0`(Vibe 칩 텍스트)·`#EFEFEF`(3위 태그 배경)는 토큰 부재 → 가장 가까운
  관용 표현(`text-white`, `bg-line/45`)으로 근사. MR에 명시.

## 링크 정책 (!24 결정과 동일)

회원가입 CTA(히어로·피날레) → `/login?mode=signup` (슬라이스 3에서 `/signup` 이전 완료 시 되돌림).
"라이브 구경하기" → `/rooms`. "이미 계정이 있다면 로그인" → `/login`.
