# 비드라이브 (BidLive)

SSAFY 15기 팀 프로젝트. 실시간 경매와 낙찰가 예측을 결합한 웹 서비스입니다.

## 구성

- `frontend/`: Vue 3, TypeScript, Vite, Pinia 기반 사용자 화면
- `backend/`: Java 21, Spring Boot, PostgreSQL, Redis, WebSocket 기반 API

## 나의 기여

박로야는 프론트엔드 개발에 참여했습니다. GitLab 커밋 기록에서 실시간 경매 화면의 미디어 토큰 처리, 음소거·자동재생 동작, 접근성 안내와 반응형 화면 수정 등을 확인할 수 있습니다.

## 출처와 범위

이 저장소는 [SSAFY GitLab 팀 저장소](https://lab.ssafy.com/s15-webmobile1-sub1/S15P11A704)의 `dev` 브랜치에서 만든 **공개용 코드 스냅샷**입니다. 팀 공동 작업이며 모든 코드를 박로야가 작성한 것은 아닙니다. GitLab의 원래 커밋 이력은 포함하지 않았습니다.

원본에는 환경 설정 파일과 인증서 형식 파일이 있어, 공개 복사본에서는 개인 과제(`sub1/`), 환경 변수 파일, 배포 설정을 제외했습니다. 실행에는 별도의 로컬 설정이 필요하며, 각 폴더의 README를 참고할 수 있습니다.
